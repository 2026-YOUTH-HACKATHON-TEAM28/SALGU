# 낱말 목록과 패턴 (그대로 사용)

실제 통화 18건을 거치며 모은 표현입니다. `extract.py`·`dedupe.py`·`instruction.py`의 값 원문이고, 코드는 새로 짜도 이 목록은 그대로 쓰면 됩니다. 정규식은 Python `re` 문법입니다.

## 화자 구분 (`label_speakers`)

| 이름 | 값 | 쓰임 |
|---|---|---|
| `AI_MARKS` | `살구`, `AI 비서`, `에이아이 비서`, `AI비서`, `전화드린` | 이 표현을 말한 쪽이 AI(앞에 있는 것부터 확인) |
| `PICKUP` | `^\s*(여보세요\|네[,.\s]\|네$\|예[,.\s]\|.{0,12}(부동산\|공인중개사)(입니다\|이에요\|예요))` | 첫 줄이 이렇게 받는 말이면 그 사람이 중개사, 두 번째 화자가 AI |
| `QUESTION` | `(\?\|까요\|나요\|인가요\|되나요\|있나요)\s*$` | 위 둘 다 없을 때 질문을 많이 한 쪽이 AI |

## 정정·불확실 (`superseded`, `corrected_into`)

| 이름 | 값 | 쓰임 |
|---|---|---|
| `_CORRECTION` | `(아\s*잠깐\|잠깐만\|잠시만\|아\s*아니\|아니다\|아니[요고,.\s]\|옆방\|그거\s*말고\|말고요\|정정\|다시\s*말(?:하면\|씀)\|아\s*참)` | 이 표지 뒤에 같은 항목의 다른 값이 나오면 앞 값은 버리고 뒤 값을 받음 |
| `_HEDGE` | `(던가\|일걸\|일\s*거예요\|확인해\s*봐야\|확실하지\|정확하지는\|정확히는\s*모르\|기억이\s*안)` | 중개사도 확실하지 않은 값 → 버림(`hedged`) |
| `_TIME_NO` | `(안\s*되\|안\s*돼\|어렵\|힘들\|곤란)` | "2시는 힘들고 5시 어때요?"에서 앞 시각은 버림 |

## 확정 수락 (`_accepted_time`)

| 이름 | 값 | 쓰임 |
|---|---|---|
| `_ASKS` | `(\?\|까요\|나요\|될까\|괜찮으세요\|되세요)\s*$` | 바로 앞 AI 줄이 시각을 묻는 질문인지 |
| `_ACCEPT` | `(네\|예\|좋\|당연\|괜찮\|그래\|그럼요\|돼요\|됩니다\|가능\|오세요\|맞아요)` | 중개사가 시각 없이 받기만 함 → 그 질문의 시각으로 확정 |
| `_REFUSE` | `(안\s*되\|안\s*돼\|어렵\|힘들\|곤란\|말고\|다른\s*(날\|시간\|때)\|글쎄)` | 이게 있으면 수락으로 보지 않음 |

## 숫자·날짜

| 이름 | 값 | 쓰임 |
|---|---|---|
| `_NOT_MONEY` | `(?!\s*(?:층\|호(?!가)\|시(?!세)\|분\|년\|개월\|월(?!세)\|일\|번\|명\|살\|평\|동\|㎡\|제곱))` | 숫자 뒤에 이게 붙으면 금액이 아님("3층", "2시"). "월세"·"시세"·"호가"는 예외 |
| `_WEEKDAY` | `(다음\s*주\|담주\|이번\s*주)?\s*([월화수목금토일])요일` | 날짜 확인 |
| `_MONTH_DAY` | `(?:(\d{1,2})\s*월\s*)?(\d{1,2})\s*일(?!\s*(?:간\|정도\|째\|이내\|안에))` | 날짜 확인("3일간"은 제외) |
| 한국어 숫자 | `일이삼사오육칠팔구십백천`, 시각은 `한 두 세 네 다섯 여섯 일곱 여덟 아홉 열 열한 열두` | "천에 육십오", "두 시 반" 읽기. "칠만 원이에요"의 '이'는 2가 아님 |
| 상한 | 방 `MAX_LISTINGS = 5`, 가능 시간 `MAX_SLOTS = 6` | LLM이 더 줘도 자름 |

## 중복·통화 문구

| 이름 | 값 | 쓰임 |
|---|---|---|
| `GENERIC` | `오피스텔`, `빌라`, `주택`, `원룸`, `건물`, `아파트` | 건물 이름 비교 전에 뺌("해든빌라" = "해든") |
| `TYPE_LABEL` | `officetel` → 오피스텔, `villa` → 원룸(빌라) | 지시문에서 유형 말하기 |
| `ROOM_CHECK` / `UNIT_ASK` | "그 방 아직 있죠?" / "호수가 몇 호예요?" | 확정 통화 방 확인 |
