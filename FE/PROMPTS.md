### 8. 지도 403, AI 연결 여부

> 화면 개선 진행해줘. 현재 지도에서 403 access denied 떠. 현재 AI 연결 되어 있어?

- 원인: 보안 헤더가 `Referrer-Policy: no-referrer` 라 OpenStreetMap 타일 요청에 출처가 빠짐. OSM 타일 이용 정책상 출처 없는 요청은 403 으로 막힐 수 있음
- 수정: 출처 정책을 `strict-origin-when-cross-origin`(도메인만 보냄)으로, Leaflet 타일에도 같은 값, OSM 저작권 링크. 시험 1개 추가(36개 통과)
- 답: AI는 연결되어 있지 않음. 대화는 mock 규칙(`src/server/mock/nlu.ts`, `dialog.ts`)이고, 옛 AI 백엔드는 7번에서 내림
- 배포 전(확인 후 배포)

### 17. 대화 목록이 지도 버튼 아래로 깔림

> (화면 캡처) 지도가 켜져있는 상태에서 우측 상단 대화 누르면 지도에 있는 동네, 매물, 동선, 역, 출근권역 아이콘들이랑 겹치는 문제 있어

- 원인: 지도 위 버튼·범례(z-index 500)가 화면 전체 기준으로 쌓여서, 헤더(z-index 30) 안의 대화 목록보다 위에 그려짐
- 수정: 지도 칸(큰 지도, 채팅 속 지도, 옆 칸, 모바일 지도 탭)을 각자 안에서만 쌓이게(isolation) 하고 헤더를 그 위로. 1400px 화면에서 지도를 연 채 대화 목록을 열고 겹치던 자리(지도 버튼 위치)를 눌러 보면 대화 목록이 잡히는 것 확인
- 배포(> 배포해줘). 공개 주소 1400px 화면에서 카카오 지도를 연 채 대화 목록을 열고, 지도 버튼이 있던 자리 세 곳을 눌러 모두 대화 목록이 잡히는 것 확인

### 18. 일정·지도 버튼 다시 누르면 닫기

> 상단 일정, 지도 선택해서 노출됐을 떄, 해당 아이콘을 다시 누르면 비노출로 바꿔줘

- 헤더 일정·지도 버튼을 열고 닫는 버튼으로: 이미 보이고 있으면 닫고(PC 옆 칸 닫기, 모바일은 집 찾기 탭으로), 아니면 열기. 지도가 열린 채 일정을 누르면 일정으로 바뀜. 열려 있으면 눌린 모양(살구색)과 aria-pressed
- 확인: 화면 동작 시험 2개 추가(PC 지도·일정 열고 닫기, 모바일 일정 열고 닫기), 16개 통과
- 배포(> 배포해줘). 공개 주소 1400px 에서 확인: 지도 열기, 다시 눌러 닫기(0.6초 뒤 닫힘, 3초 뒤에도 닫힌 채), 일정 열기, 다시 눌러 닫기. 처음 카카오 지도를 불러오는 순간에 바로 다시 누르면 화면이 늦게 바뀌어 0.6초 시점에 열린 채로 보인 적이 한 번 있었고, 같은 흐름을 다시 해 보니 정상으로 닫힘

### 23. 동네 추천·가격 판단·중개사무소를 대화 에이전트에서

> 먼저 동네 추천, 가격 판단, 중개사무소목록 chat_agent로 질문 보내서 받는 형태일거야. 맞추어 수정해줘.

- 동네 찾기(찾기 버튼, 조건 고치기, 넓혀보기, 다른 동네)는 화면 조건을 한 문장 질문으로 대화 에이전트에 보내고, 돌아온 추천 엔진 후보를 '구 동'으로 묶어 동네 카드로 만듦. 점수는 후보 최고점, 실거래 건수·환산월세 범위·중간값은 후보에서
- 가격 판단: 같은 건물·면적대 시세 중앙값(market_median_*)의 환산월세 중앙값과 비교(5% 이하 적정, 15% 이하 조금 비쌈)
- 중개사무소: 에이전트 응답에 `brokers`(이름, 등록번호, 전화, 동)가 오면 그 동네 것을 쓰고, 아직 없어서 지금은 예시 목록
- 통근 시간은 에이전트가 아직 계산하지 않아 '통근 계산 전'으로 표시. 동 좌표를 모르면 자치구 중심 근처에 표시. 에이전트 결과를 못 받으면 예시 데이터로 보여 주고 그렇게 알림
- 확인: 단위 시험 5개 추가(50개 통과), 화면 동작 시험 18개 통과. 로컬 실제 에이전트(실거래 DB)로 여의도역 조건 -> 영등포구 여의도동 확인

### 24. 페이지 전체가 밀려 올라가는 스크롤 버그

### 25. BE 는 로컬에서 jar 빌드

### 26. 중개사무소를 대화 에이전트 전화 요청 초안에서, 카카오 REST 키, BE 로그인 맞춤

- 추천 엔진·chat_agent·phone_agent 원격 최신을 합침. 추천 엔진에 카카오 대중교통 통근과 중개업소 검색이, chat_agent 에 '2번 집 문의해 줘' 전화 요청 초안(contracts/call_request.md)이 생김
- 중개사무소: 전화 준비 때 동네마다 대표 후보를 에이전트에 '문의'해서 초안의 사무소(실거래 DB real_estate_agencies, 이름·등록번호·전화)를 받아 씀. 에이전트 마지막 검색이 바뀌었으면 조건으로 다시 찾고 한 번 더 물음. 못 받으면 예시 목록
- 카카오 REST 키는 Git 밖 AI/chat_agent/.env 와 서버 설정 파일에만 두고 컨테이너 환경으로도 넘김. 다만 chat_agent 가 아직 통근 계산기를 쓰지 않아 통근은 계속 '계산 전'
- 최신 추천 엔진이 httpx 를 쓰는데 chat_agent requirements 에 없어 배포 때 따로 설치(팀 코드는 그대로)
- BE 로그인: /api/me 는 {id(BE users.id), nickname}, 미로그인 401. 화면 계정 연결 키 이름을 beUserId 로 바로잡음. 공개 주소에서 카카오 이동(redirect_uri 사이트 주소), JSESSIONID, 실패 시 ?loginError=true 확인
- 확인: 단위 시험(중개사무소 초안) 추가 50개 통과, 화면 동작 시험 20개 통과. 실제 DB 시험은 Supabase 세션 모드 연결 한도(15)에 걸려 확인하지 못함

### 27. 채팅에서 mock 데이터 완전 배제

> 채팅 먼저 개선작업 진행해. 이제 채팅에 mock 데이터는 완전 배제할거야.

- 동네 추천은 대화 에이전트(실거래 추천 엔진)만 씀. 못 받으면 예시로 대신하지 않고 '동네 추천 서버에 연결하지 못했어요'로 알리고 조건 카드를 다시 보여 줌
- 동네 설명의 근거 실거래는 추천 엔진 후보만, 가격 판단은 추천 엔진 시세 중앙값만. 중개사무소는 에이전트 전화 요청 초안(실거래 DB)만 쓰고, 못 받은 동네는 전화에서 빼고 알림. 예시 중개사무소·예시 동네 좌표 제거
- 회사(학교)는 회사 목록에 없어도 이름 그대로 받음(조건 양식은 입력칸 + 추천 목록). 좌표는 카카오 장소 검색, 동네 좌표는 카카오 주소 검색(KAKAO_REST_API_KEY). 키가 없거나 실패하면 자치구 중심 근처
- 출처 표시에서 예시 값 제거(실거래 DB, 전월세전환율, 직선거리 이동 어림), 입력창 아래 안내 문구를 실거래 DB 기준으로
- 시험은 시험용 가짜 에이전트(tests/fixtures)로 바꿈(화면 코드에는 들어가지 않음)
- 확인: 로컬에서 '신촌역으로 통학' 이 회사 이름 그대로 들어감. 받은 카카오 REST 키는 형식 오류(401)로 거절, 실제 추천은 Supabase 연결 한도로 확인 못 함

### 30. 내 번호로 먼저 받아 보기를 실제 통화로

- 전화 에이전트가 있으면 시험 전화도 전화 에이전트 문의 통화로 실제로 걺(중개사무소 문의와 같은 대본, 등록번호는 test-시각). 진행 상태와 통화 내용을 시험 전화 칸에 보여 줌. 번호는 가린 값만 남김
- demo 는 어떤 번호를 넣어도 시연 번호로만 걸어서, 화면 서버가 시연 번호(PHONE_TEST_NUMBERS, 배포 때 전화 에이전트 설정에서 가져옴)가 아니면 미리 막고 안내

### 31. 전화 mock 배제, 이대로 전화하기는 본인 번호로만

> 전화 받았어. 전화도 mock인 내용 전부 배제할거야. 전화 테스트는 내가 진행할테니깐 하지마.
> 이대로 전화하기 누르면 자신 전화번호 누르라고 alert 창 뜨게 해줘.
> 이 프로젝트에서 아직 실제 부동산에 연락하면 안되기 때문에 전화 로직에는 자기 전화번호 입력하게 해줘.

- 화면 서버의 흉내 통화(문의·확정·시험 전화 시뮬레이션) 경로를 없앰. 전화는 전화 에이전트로만 걸고, 연결이 안 되거나 전화 에이전트가 mock 모드면 '전화 서버에 연결하지 못했어요'로 막음
- 이대로 전화하기를 누르면 화면 안 창(브라우저 alert 대신)에서 본인 휴대폰 번호를 받음. 중개사무소마다의 문의 통화를 실제 사무소 번호가 아닌 이 번호로만 걺(확정 통화도 전화 에이전트가 같은 번호로). 번호는 가린 값만 남김
- 시험 서버(demo)는 등록된 시연 번호만 받음(다른 번호는 안내하고 막음)
- 전화 시험은 사용자가 직접 진행(이번 작업에서는 걸지 않음)

### 32. 내 번호로 먼저 받아 보기 제거, 전화 전 준비에 중개사무소 전화번호

> 내 번호로 먼저 받아 보기 영역은 제거해줘. '이대로 전화하기'로 충분할 것 같아.
> 전화 전 준비에서 각 부동산 전화번호가 나오게 해줘
> 완료되면 바로 배포해

- 시험 전화 영역과 서버 처리(시험 전화 동작, 하루 3번 한도, 상태 읽기)를 모두 지움
- 전화 전 준비 카드에 동네마다 중개사무소 이름·전화번호·등록번호를 보여 줌. 실제로 물어볼 곳(동네마다 PHONE_BROKERS_PER_DONG 곳)과 이번엔 걸지 않는 곳을 구분. 전화는 이 번호 대신 본인 번호로 건다고 안내

### 33. 카카오톡 알림 연결

> 카카오톡 알림 연결 진행해.

- 전화 에이전트 알림(C6)은 아직 구현 전(io.md: notifications 항상 빈 배열)이라 화면 서버가 카카오톡 '나에게 보내기'로 보냄
- 연결: 일정 화면의 카카오톡 연결 -> 카카오 동의 화면(talk_message) -> /api/notify/kakao/callback 에서 토큰을 받아 사용자 계정에 저장(화면으로는 내보내지 않음). 연결 해제는 토큰 삭제. 흉내 연결 제거
- 보내는 때: 중개사무소 문의 통화가 모두 끝났을 때(방 있음·없음·확인 못 함 수), 방문이 확정됐을 때, 방문 전날 저녁 8시 이후와 1시간 전(5분마다 확인, 한 번씩). 시험 알림 버튼은 실제로 보냄. 토큰 만료면 갱신, 끊겼으면 연결을 풀음
- 앱 키: 카카오 로그인 앱의 REST API 키·시크릿(KAKAO_CLIENT_ID/SECRET). 서버는 배포 때 BE 비밀 설정에서 가져옴
- 카카오 개발자 콘솔에서 필요한 것: Redirect URI 에 <사이트>/api/notify/kakao/callback, 동의 항목 '카카오톡 메시지 전송', 플랫폼 Web 사이트 도메인

### 34. 화면에서 입력한 번호로 전화(전화 에이전트 수정)

> 전화 에이전트 영역 코드 수정 진행해. 이제 demo에 등록된 사용자가 아니라 화면에서 사용자가 입력한 전화번호로 전화할 수 있도록 진행해.
> 완료되면 즉시 배포해

- 전화 에이전트(AI/phone_agent): PHONE_AGENT_DIAL_REQUESTED=1 이면 demo 도 요청에 담긴 번호로 걸음(확정 통화는 처음 건 번호). 안전장치로 휴대폰 번호(01x)만 받고 그 밖의 번호는 phone_not_allowed 로 거절. 상태 응답에 dial(requested/demo_numbers) 추가, 문서 갱신

- 배포 때 서버 전화 에이전트 설정에 PHONE_AGENT_DIAL_REQUESTED=1 을 넣음

### 35. 매물 추천 알고리즘 문서에 맞추기

> (매물 추천 알고리즘 관련 설명 파일 전달) 파일 읽고 조건 맞춰서 수정 진행해

- chat_agent 원격 최신 합침. chat_agent 가 추천 엔진을 통근 계산기 없이 부르고(회사 조건 제거) 중개사무소 검색도 쓰지 않아 문서와 달랐음
- chat_agent(AI/chat_agent): 카카오 REST 키가 있으면 KakaoCommuteProvider 와 교통 공공데이터(버스·지하철 DB)를 넘겨 실제 통근·환승·요금·배차·첫차·막차·주변 정류장까지 계산, 살 곳을 말하지 않으면 엔진이 회사 기준 10→20→40km 로 넓힘. POST /api/realtors 로 find_nearest_realtors(카카오 AG2 거리순 + 중개업소 DB 대조, 폐업·휴업 제외)
- 화면: 동네 카드에 실제 통근 시간·환승·경로(노선·승하차)·도보·거리·요금·카카오맵 경로 링크, 버스·지하철 배차와 막차, 가까운 버스정류장. 조건 질문에 환승·버스 배차 조건도 보냄. 전화 준비의 중개사무소는 대표 후보 주소로 추천 엔진 중개사무소 검색(실제 좌표)을 먼저 쓰고, 못 받으면 전화 요청 초안
- 서버 chat_agent 설정: DB 트랜잭션 모드(6543), 추천 시간 60초. 화면 서버의 에이전트 응답 대기 75초
- 확인: 로컬 실제 DB·카카오로 강남역 조건 -> 대치·역삼·양재동, 통근 12~29분, 2호선 배차 5.5분, 중개사무소 3곳(54~130m)
